# UI/UX テストケース一覧

作成: 2026-11-05（PR #65 のレビューをもとにした、実機で確かめる手順）。これは手順の一覧で、結果は書かない。実施したら、日付つきの結果を別に残す（このディレクトリの `dictation.md` / `meeting.md` に追記する）。

- 対象 OS: Mac = M、Windows = W。両方に欄がある項目は、同じ結果になることが期待。
- 優先度: **P1** = 出す前に必ず / **P2** = 通常 / **P3** = あれば確かめる。
- 「要件」の列は `docs/spec/` の ID。振る舞いの正しさの根拠はそこにある。
- 準備: ①新規ユーザー（初回起動）②既存ユーザー（設定・履歴・会議が溜まっている）の 2 つの環境、外付けマイクと内蔵マイク、会議アプリ（Zoom / Meet / Teams のどれか）、ネットワークを切れる状態。
