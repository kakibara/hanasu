## ハイライト

設定の画面の細かい直しの版です。「スニペット」を開くと設定の画面が崩れていたのを直し、AI の選択肢を、この端末の中で動くものから先に並べるようにしました。

## 改善

- 設定の「AI」の選択肢を、この端末の中で動くもの（ローカル・Apple）を左に、外部の API に送るもの（Gemini・Claude）を右に並べるようにしました。Windows は「ローカル・Gemini・Claude」の順です。選んでいた AI はそのままです（Mac / Windows）。
- 設定の説明文のうち、「「AI」タブ」や「Gemini か Claude」のように古くなっていた言い方を、今の設定の画面に合わせて直しました。ローカルや Apple を選んだときのことも書いています（Mac）。
- 韓国語・中国語の表示で、「ここ重要」の訳を議事録の印と同じ言葉にそろえました（Mac）。

## 不具合の修正

- 設定で「スニペット」を開くと、サイドバーや見出しが見えなくなり、画面全体が崩れていました（Mac）。

## 気をつけること

- 「スニペット」の画面と、Windows の AI の選択肢の並びは、画面の描き出しで確かめたもので、実際のウインドウではまだ確かめていません。
