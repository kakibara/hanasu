## ハイライト

音声入力で、話した内容を日本語に訳して入力できるようになりました。翻訳する言語は設定で選べます。音声入力のマイクも、録音中に切り替えられるようになりました（Mac）。

## 新しい機能

- **日本語への翻訳**（Mac / Windows）: 設定の「一般」→「翻訳する言語」で、English と日本語を選べます（既定は English だけ）。日本語を選ぶと、録音中の表示に「日本語」が出て、英語などで話した内容を自然な日本語に訳して入力します。「翻訳して入力」のショートカット（`⌥⇧ Space`、Windows は `Ctrl + Alt + Shift + Space`）は、選んだ言語のうち English → 日本語の順で最初の言語で始まります。
- **音声入力のマイク**（Mac）: 設定の「一般」→「マイク」で、音声入力と「選択を声で編集」に使うマイクを選べます。録音中は、表示の右下のマイクのボタンから、録音を止めずに切り替えられます。会議の記録のマイクは今までどおり「会議」タブで選びます。
- **整形の言語**（Mac / Windows）: 設定の「AI」→「整形の言語」で、「話した言語」（既定）と「日本語に統一」を選べます。
- **文字起こしの言語の一覧**（Mac）: 設定の「一般」→「文字起こし」の言語を、11 の言語の一覧から選べるようになりました。初めて使うときは、Mac のシステムの言語になります。
- **会議の削除**（Mac / Windows）: 会議ノートの一覧の右クリック、`⌫`（Windows は `Delete`）、詳細の上のゴミ箱のボタンで、記録した会議を削除できます。会議のフォルダはゴミ箱に移るので、ゴミ箱から戻せます。記録中・処理中・議事録を作り直している会議は削除できません。
- **アイコンを出す場所**（Mac）: 設定の「一般」→「アイコンの表示」で、「メニューバーだけ」「Dock だけ」「メニューバーと Dock の両方」（既定）から選べます。「Dock だけ」では、Dock のアイコンを右クリックするとメニューバーと同じメニューが出て、録音中はアイコンに ● が付きます。

## 改善

- 会議ノートのタイトルの欄に、薄い枠と鉛筆の印を出すようにしました。書き換えられることが見てわかります（Mac / Windows）。
- 議事録を作り直している間、その会議の詳細と一覧の行に、作り直し中の印が出るようになりました（Mac）。
- 録音中の表示の言語の切り替えで、「日本語」の表記を「話した言語」に変えました。

## 不具合の修正

- （Mac）常駐しているだけで、CPU を 8〜10% ほど使い続けていました。画面に出ていない録音中の表示などが描き直され続けていたためです。
- （Mac）会議ノートで議事録を作り直すと、選んでいた会議から一覧の先頭の会議に移っていました。
- （Mac）会議のタイトルを書き換えてほかの場所をクリックすると、変更が消えていました。

## 気をつけること

- 整形の既定が「話した言語」になりました。英語で話した部分は、日本語に訳さず英語のまま残ります。前の版のように日本語にそろえたいときは、設定の「AI」→「整形の言語」を「日本語に統一」にしてください。
- 日本語への翻訳は、AI に送る指示の組み立てまでを確かめたもので、実際の AI の訳の出来はまだ確かめていません。
- 録音中のマイクの切り替え、アイコンの表示の切り替え、会議の削除は、画面の描き出しとテストで確かめたもので、実際の操作ではまだ十分に確かめていません。Windows 版の翻訳の設定と表示も、Windows の実機ではまだ見ていません。
- （Mac）メニューバーにアイコンが出ないときは、システム設定の「メニューバー」→「メニューバーでの表示を許可」で Hanasu がオンになっているかを確かめてください。
