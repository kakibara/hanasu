## ハイライト

自分の書いた文章から文体を学び、「カスタム文体」としてアプリごとの音声入力に使えるようになりました。会議の記録中にアプリが落ちても録音が残り、あとから文字起こしと議事録を作り直せます。

## 新しい機能

- **文章から文体を学ぶ**（Mac / Windows）: 設定 →「アプリ別」→「カスタム文体」の「文章から学ぶ…」で、文章を貼り付けるかファイル（Word の .docx・.txt・.md）を選ぶと、AI が文体のルールを書き出します。読んで直してから保存でき、アプリの文体の選択欄から選べます。学ぶのに使った文章は保存しません。
- **落ちた会議を録音から作り直す**（Mac / Windows）: 記録中にアプリが落ちても、録音はその直前まで残るようになりました。起動し直したあと、その会議の「録音から文字起こしと議事録を作る」を押すと、記録を止めたときと同じように文字起こしと議事録を作ります。
- **アプリ別の文体**（Windows）: Mac と同じように、前面のアプリに合わせて整形の文体を変えます。設定の「アプリ別」タブから変えられます。
- 記録中に ⌘Q で終えようとしたとき、確かめるようにしました（Mac）。「終了」を選ぶと、録音を閉じてから終えます。

## 改善

- 音声入力の整形の AI をローカルにしているとき、録音を始めた直後からモデルを裏で読み込んでおくようにしました（Mac / Windows）。話し終えてから文字が入るまでの待ち時間が短くなります。選択の編集でも同じです（Mac）。
- 設定 → AI →「整形の言語」の「日本語に統一」を、文字起こしの言語にそろえる選択肢にしました（Mac / Windows）。文字起こしの言語が英語なら「英語に統一」、韓国語なら「한국어로 통일」のように出ます。

## 不具合の修正

- 会議の記録中に、会議ノートの画面のレイアウトが原因でアプリが落ちることがあったのを直しました（Mac）。
- ローカルの AI で、整形と議事録など違うモデルを続けて使ったとき、あとから起動したモデルのサーバーを止めてしまうことがあったのを直しました（Mac）。

## 気をつけること

- **Windows ではアプリ別の文体が既定でオンになります。** Slack・Teams はチャット、Outlook はメール、Word は です・ます調 に整形が変わります。前のままがよいときは、設定の「アプリ別」タブでオフにしてください。
- 文字起こしの言語が日本語以外で「日本語に統一」を選んでいた方は、更新すると自分の文字起こしの言語にそろうようになります。日本語にしたいときは和訳を使ってください。
- 次のことは、まだ実機で確かめていません。うまく動かないときは、ログを添えて知らせてください。
  - 実際の AI で学ばせた文体が、音声入力の結果に表れること
  - 落ちた会議の作り直しを Whisper・Gemini で行うこと、Windows で行うこと
  - Windows のアプリ別の文体・カスタム文体の画面、ローカルのモデルの先読み
