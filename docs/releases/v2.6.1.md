## ハイライト

Windows の `hanasu` コマンドで、会議を並べる・読む・探すのが速くなりました（Windows）。

## 改善

- `hanasu meetings list / show / search` が速くなりました（Windows）。会議を並べて読むときのメモリの片付け方を変えました。架空の会議 1,000 件で測ると、`meetings list` は約 1.1 秒から約 0.7 秒に、`meetings search` は約 2.3 秒から約 2.0 秒になりました。MCP から会議を読む・探すときも同じように速くなります。

## 気をつけること

- 片付け方を変えたので、`hanasu` コマンドと `hanasu mcp` が使うメモリが前の版より少し増えることがあります（Windows）。どのくらい増えるかは、まだ測っていません。
- Mac 版は v2.6.0 から変わっていません。
