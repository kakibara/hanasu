## ハイライト

Windows 版から、使っていなかった音声合成の部品（espeak-ng、GPL-3.0）を取り除きました（Windows）。v1.3.0〜v2.6.1 の Windows 版の zip は配布を取り下げるので、Windows で使っている方はこの版に更新してください。

## 不具合の修正

- 会議の話者分離に使うライブラリ（sherpa-onnx）を新しい版に上げ、その中に入っていた音声合成の部品（espeak-ng、GPL-3.0 のライセンス）を外しました（Windows）。Hanasu はこの部品を使っていませんでしたが、Hanasu のライセンスと合わないため、v1.3.0〜v2.6.1 の Windows 版の zip は配布を取り下げます。
- ユーザーのフォルダ名に日本語などがあると、会議の相手側の話者を分けられなかった（または記録の後処理でアプリが終わった）かもしれない問題を直しました（Windows）。
- 話者分離の準備に失敗したとき、アプリが終わらずに、相手側を「相手」1 人にまとめて続けるようにしました（Windows）。
- 同梱しているライブラリのライセンスの表示（`THIRD_PARTY_NOTICES.md`）に足りなかったものを足しました（Windows）。

## 気をつけること

- 日本語などを含むフォルダ名での話者分離と文字起こしは、まだ Windows の実機で確かめていません。話者がうまく分かれないときは、ログ（`%LOCALAPPDATA%\Hanasu\Logs\hanasu.log`）を添えて知らせてください。
- Mac 版は v2.6.0 から変わっていません。
