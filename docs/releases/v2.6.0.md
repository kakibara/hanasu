## ハイライト

ターミナルや AI エージェントから Hanasu を使える `hanasu` コマンドを足しました（Mac・Windows）。過去の会議を読む・探す・質問する、文章を音声入力と同じように整えることが、コマンドや MCP からできます。設定の「コマンドと MCP」から、Claude Desktop・ChatGPT（Codex）・Claude Code にボタン 1 つでつなげます。

## 新しい機能

- **`hanasu` コマンド**（Mac・Windows）: `hanasu meetings list / show / search` で会議を並べる・読む・探す、`hanasu actions` で会議をまたいでアクションアイテムを並べる、`hanasu ask` で過去の会議について質問する、`hanasu refine`・`hanasu edit`・`hanasu dict apply` で音声入力と同じ整形・書き換え・辞書の置き換えをする、ことができます。`--json` で決まった形の JSON を出します。Mac はアプリと同じ実行ファイル、Windows は zip の `cli\hanasu.exe` です。設定 →「コマンドと MCP」で PATH に入れられます。
- **MCP サーバー**（Mac・Windows）: `hanasu mcp` で MCP サーバーとして動き、AI エージェントから会議を読む・探す・質問することができます。
- **AI アプリにつなぐ**（Mac・Windows）: 設定 →「コマンドと MCP」の先頭から、Claude Desktop・ChatGPT（Codex）・Claude Code に Hanasu をボタン 1 つでつなぐ・外すことができます。書き換える前の設定ファイルは `.hanasu-backup` として残します。
- **管理者のポリシー**（Mac）: `hanasu` コマンドや MCP を使えなくしたり、使える AI を絞ったりできます。

## 改善

- Dock のアイコンを押しても、設定画面が開かなくなりました（Mac）。設定画面は、メニューバーのアイコンか Dock のアイコンを右クリックしたメニューの「設定…」、またはアプリのメニュー（⌘,）から開きます。
- 英語・韓国語など空白で語を区切る言語で、会議の発言・音声入力の文がくっつかず、空白 1 つでつながるようになりました（Mac・Windows）。日本語・中国語は今までどおりです。
- Whisper が無音のときに書く決まり文句や音の注記を、日本語だけでなく 17 言語で捨てるようにしました（Mac・Windows）。
- 英語・ドイツ語などの表示で、履歴と会議の日付がその言語の並びになりました（Mac）。
- 辞書の置き換えの「語の途中では置き換えない」が、アクセント付きの文字やキリル文字でも効くようになりました（Mac・Windows）。

## 不具合の修正

- 文字起こしの言語をロシア語などにしたとき、設定の一覧で今の言語が空になっていました（Mac）。
- 画面の文字から語を取るとき、「Müller」が「ller」のように途中で切れていました（Mac）。
- 標準の音声認識で、地域だけが違う言語（es-MX など）を選ぶと認識できませんでした。同じ言語の別の地域を使うようにしました（Windows）。
- Whisper で英語の語の一覧が空になることがありました（Windows）。
