## ハイライト

会議の議事録に使う発言を選べるようになりました。範囲を決める・特定の発言や話者を除く・記録中に「オフレコ」にする、のどれでも、使わない発言は議事録に入りません。翻訳して入力する言語も、英語・日本語のほかに 17 言語すべてから選べます。

## 新しい機能

- **議事録に使う範囲を決める**（Mac / Windows）: 会議ノートの文字起こしで発言を右クリックし、「ここから議事録に使う」「ここまで議事録に使う」を選ぶと、その範囲で議事録を作ります。会議の前の雑談や、終わったあとの話を外せます。
- **発言・話者を除く**（Mac / Windows）: 発言ごとに議事録から除けます（あとで戻せます）。通訳などの話者の発言もまとめて除けます。「議事録に使う発言を選ぶ」でチェックボックスを出すと、Shift を押しながら押して範囲をまとめて切り替えられます。
- **オフレコ**（Mac / Windows）: 記録中に「オフレコ」ボタンを押して始め、もう一度押して終えると、その間の発言を議事録に使いません。録音と文字起こしは続きます。
- 使わない発言は、文字起こしに薄く残り、理由のバッジが付きます。議事録・話者の名前の推測・書き出しには渡しません。Mac では、AI チャット・過去の会議への質問・辞書の提案にも渡しません（検索には出ます）。選び方を変えると「作り直すと反映されます」と出ます。議事録は自動では作り直しません。
- **記録中のスリープ**（Mac / Windows）: 記録中にスリープした（MacBook を閉じた）ときは、復帰の直後に「スリープ前までで止める」か「記録を続ける」かを選べます。止めると、音声と文字起こしをスリープした時点までにそろえます。続けると、スリープしていた時間は経過時間に入りません。
- **翻訳の言語が 17 言語に**（Mac / Windows）: 設定の「一般」→「翻訳する言語」で、英語・日本語に加えて、中国語（簡体・繁体）・韓国語・スペイン語・フランス語・ドイツ語など、Hanasu が対応する 17 言語から選べます。3 つ以上選ぶと、録音中の表示には 2 つをボタンで出し、残りはメニューから選べます。
- **アプリ別の出力言語も 17 言語に**（Mac）: 設定の「アプリ別」の出力言語で、English・日本語のほかの言語も選べます。そのアプリで録音を始めると、その言語への翻訳で始まります。

## 改善

- 新しい版を知らせる画面で、リリース文を見出し・箇条書き・太字の形に整えて出すようにしました。開いたときは先頭から見え、全文をスクロールして読めます（Mac / Windows）。
- 新しい版を知らせる画面で、リリース文のスクロールが重かったのを軽くしました（Mac）。

## 不具合の修正

- 音声入力の履歴に、知らない入力のしかたの項目（新しい版で訳した言語など）が 1 件でもあると、履歴全体を読み込めませんでした。知らない項目もそのまま読み、そのまま保存するようにしました（Mac）。

## 気をつけること

- この版で English・日本語のほかの言語に翻訳して入力すると、その履歴は v2.0.1 までの版では読めません。この版から前の版に戻すと、音声入力の履歴が読み込みのエラーになります（ファイルは上書きしません）。
- 「ここ重要」のタブとそのコピーには、議事録に使わないことにした発言もまだ入ります。
- 議事録に使う発言の選び方・オフレコ・スリープのときの選択は、テストと画面の描き出しで確かめたもので、実際の操作ではまだ十分に確かめていません。Windows の画面は、まだ実機で動かしていません。
- English・日本語のほかの言語への翻訳は、AI の実際の結果をまだ確かめていません。
