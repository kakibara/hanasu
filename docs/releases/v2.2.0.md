## ハイライト

Mac の会議ノートを作り直しました。議事録を 1 枚の文書として読み、要点の時刻を押すと元の発言へ移り、そこから録音を聞き直せます。会議の文字起こしから辞書の候補を作り、辞書の置き換えを会議の文字起こしにも当てられるようにもなりました。

## 新しい機能

- **会議ノートの新しい画面**（Mac）: 真ん中に、要約・アクションアイテム・議事録・「ここ重要」・メモを上から順に 1 枚の文書で出します。右のパネルで「文字起こし｜AI チャット」を切り替えます（ツールバーのボタンか ⌥⌘I で出し入れ）。会議への操作はツールバーと「…」のメニューにまとめ、左の一覧は「今日・昨日・今週・先週・月ごと」に分けました。
- **議事録から元の発言へ**（Mac）: 議事録の要点の行末に `12:34` のような時刻の印が付き、押すと右の文字起こしのその発言へ移ります。コピーや書き出し（Markdown・Slack・リマインダー）では印を外します。Windows でも、議事録の表示とコピーでは印を外します。
- **録音を聞き直す**（Mac）: 文書の下の再生のバーで、会議の録音を聞けます。再生中の発言は文字起こしで示します。15 秒戻る・進む、速さ（1〜2 倍）、「自分」「相手」の片方ずつの消音、スペースキーでの再生と一時停止ができます。会議の記録中と音声入力中は再生しません。
- **記録中の画面**（Mac）: 真ん中に文字起こし、右に「メモ｜AI チャット」と「★ ここ重要」を出します。記録を止めると同じ画面のまま文書になり、「文字起こし → 話者の区別 → 議事録」のどこまで進んだかを出します。
- **会議から辞書を作る**（Mac / Windows）: 会議ノートの「辞書」のメニュー（Mac はツールバーの本のアイコン、Windows は「辞書…」のボタン）→「この会議から辞書の候補を探す…」で、その会議の文字起こしと議事録から、AI が辞書の候補を挙げます。選んだものだけが辞書に入ります。オフレコの区間と、議事録に使わないと除いた発言は送りません。
- **会議の文字起こしにも辞書の置き換え**（Mac / Windows）: 辞書の置き換えルール（例: `ストックマーク => Stockmark`）を、記録を止めたあとの会議の文字起こしにも当て、そのあとで議事録を作ります。設定の「会議」→「文字起こしに辞書の置き換えルールを当てる」でオフにできます。前の会議も、「辞書」のメニューから今の辞書を当て直したり、認識したままの文に戻したりできます。

## 気をつけること

- 新しい会議ノートの画面・録音の再生・時刻の印は、テストと画面の描き出しで確かめたもので、実際の録音・再生ではまだ十分に確かめていません。再生の音のずれ、明るい表示・暗い表示での色の見え方に気づいたことがあれば教えてください。
- 時刻の印は、議事録を作るときに AI が付けます。この版より前に作った議事録には付きません（作り直すと付きます）。長い会議で文字起こしを縮めて AI に渡したときは、時刻がずれるので印を付けません。
- 会議ノートのウインドウの最小の大きさが 1040×560 になりました。
- Windows の会議ノートの画面は、今までのタブのままです（Mac と同じ構成にするのは、このあとの版で）。
- この版で作った議事録（`minutes.md`）には時刻の印が文字のまま入るので、前の版で開くと `[12:34]` のように見えます。
- 会議から辞書を作る機能と辞書の当て直しは、AI の実際の結果と Windows の画面を、まだ実機で十分に確かめていません。
