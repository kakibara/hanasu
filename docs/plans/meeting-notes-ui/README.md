# 会議ノートの新しい UI の見本

[../meeting-notes-ui.md](../meeting-notes-ui.md) の計画の見本。Claude の Design のキャンバス（`.dc.html` の形式）で描いたものの元のファイル。2026-11-09。

| ファイル | 状態 |
| --- | --- |
| `Main.dc.html` | 1. 記録後の会議ノート（要約・アクションアイテム・本文・ここ重要、後ろ側のパネルの文字起こし、再生のバー） |
| `Live.dc.html` | 2. 記録中（真ん中に文字起こし・後ろ側に「メモ｜AI チャット」、音が入らない警告の帯） |
| `Processing.dc.html` | 3. 記録を止めた直後（議事録を作成中の段階の帯、処理中は読むだけのメモ） |
| `Select.dc.html` | 4. 議事録に使う発言を選ぶ（ダークモード、パネルを広げた状態、作り直しを促す帯） |

見た目は macOS の標準（システムの字体・色・ツールバーのまとまり）に合わせている。実装は SwiftUI の標準の部品で作り、色はシステムの色を使う。
